# askuksov/tap

Homebrew casks for my apps.

```sh
brew install --cask askuksov/tap/kombucha
brew install --cask askuksov/tap/kokos
```

| Cask | App |
| --- | --- |
| `kombucha` | [Kombucha](https://github.com/askuksov/kombucha), battery charge limiting for macOS from the menu bar |
| `kokos` | [Kokos Password Manager](https://github.com/askuksov/kokos-app), a local-first, encrypted password manager (Apple Silicon) |
